# 📱 TheGent Mobile Companion

## WP-17002: Flutter + Dart

Mobile extension for agent monitoring and on-the-go approvals.

### Key Features
- **Push Notifications**: Receive real-time alerts for policy gates and agent failures.
- **Biometric Approval**: One-tap approval for sensitive actions using FaceID/Fingerprint.
- **Status Dashboard**: Compact view of system health and active runs.

### Tech Stack
- **Framework**: Flutter
- **Language**: Dart
- **Notifications**: Firebase Cloud Messaging (FCM)
- **Local Storage**: Hive / Sembast
