# ArgisRoute

ArgisRoute is the Go routing service referenced by the thegent API and unified
work-stream specifications.

This directory preserves the recovered PhenoSchema ArgisRoute specifications:

- `SPEC.md` - routing-system specification
- `SOTA.md` - research notes
- `ADR.md` - consolidated architecture decision record
- `ADR-001.md` through `ADR-003.md` - original top-level ADRs
- `adr/ADR-001-architecture-overview.md` through
  `adr/ADR-005-integration-api.md` - detailed ADR set

The recovered Go schema types live at
`services/argisroute/schemas/schemas.go`.
