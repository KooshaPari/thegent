# Frequently Asked Questions (FAQ)

## General Questions

### What is Ante?
Ante is a modern AI CLI tool that provides both interactive and programmatic interfaces for working with AI agents and large language models. It supports multiple models, custom skills, and agent organization.

### How do I get started?
See the [Getting Started Guide](./getting-started.md) for a quick introduction. The guide covers basic concepts and first steps with Ante.

### What are the system requirements?
Ante runs on modern systems with Python support. Check the [Getting Started Guide](./getting-started.md) for specific requirements.

## Features & Capabilities

### What is a Sub-Agent?
Sub-agents are independent AI agents that can run within the same Ante session. Each agent can have its own configuration, memory, and behavior. Learn more in [Sub-Agents](./features/sub-agents.md).

### Can I use Ante offline?
Yes! Ante has an experimental Offline Mode feature. See [Offline Mode](./features/offline-mode.md) for details and setup instructions.

### What models does Ante support?
Ante supports multiple model providers through its provider system. View the complete list in [Model & Provider Catalog](./features/model-catalog.md).

### How do I add custom skills?
Custom skills extend Ante's capabilities. Refer to [Skills](./features/skills.md) for comprehensive documentation on creating and using skills.

### What are Tools?
Tools are functions and capabilities that agents can use. See [Tools](./features/tools.md) to learn about built-in tools and creating custom ones.

## Using Ante

### Interactive vs Headless Mode
- **Interactive Mode**: Uses the Terminal UI (TUI) for real-time interaction. See [Interactive TUI](./guides/interactive-tui.md).
- **Headless Mode**: Run Ante without UI for automation. See [Headless Mode](./guides/headless-mode.md).

### How do I configure Ante?
Use the Preferences system to customize Ante's behavior. See [Preferences](./features/preferences.md) for all available options.

### Can I use memory in Ante?
Yes! Ante includes a persistent memory system for agents. Learn more in [Memory](./features/memory.md).

### How do I benchmark agents?
See [Evaluation & Benchmarking](./guides/eval-benchmark.md) for information on testing and comparing agent performance.
