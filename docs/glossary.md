# Glossary

This document contains definitions of key terms used in the Phenotype ecosystem.

## A

**API** - Application Programming Interface. A set of protocols for building software applications.

**Auth** - Authentication. The process of verifying identity.

## C

**CLI** - Command Line Interface. A text-based interface for interacting with software.

**Config** - Configuration. Settings that control program behavior.

## L

**LLM** - Large Language Model. AI models that process and generate text.

**Logging** - Recording of system events for debugging and monitoring.

## M

**MCP** - Model Context Protocol. A protocol for AI tool interaction.

**Middleware** - Software that acts as a bridge between applications or components.

## P

**Package** - A collection of related code files that can be distributed together.

**Provider** - A service that provides LLM access (OpenAI, Anthropic, etc.)

**Proxy** - An intermediary that forwards requests between client and server.

## R

**Repo** - Repository. A storage location for code and version history.

**Router** - Component that directs requests to appropriate handlers.

## S

**SDK** - Software Development Kit. A set of tools for building applications.

**Streaming** - Data transfer method where data is sent in sequential chunks.

## T

**Token** - A credential used for authentication or API access.

**Translator** - Component that converts between different API formats.

## Terms by Surface

### CLI Terms
- `helios` - Main CLI command
- `run` - Start the server
- `stop` - Stop the server
- `providers` - Manage providers
- `auth` - Manage authentication

### API Terms
- `endpoint` - URL path for API access
- `method` - HTTP method (GET, POST, etc.)
- `request` - Incoming API call
- `response` - Outgoing API data

### Auth Terms
- `OAuth` - Open standard for access delegation
- `API Key` - Token for API authentication
- `Token Refresh` - Process of obtaining new credentials
- `Token Storage` - Persistent storage for credentials
