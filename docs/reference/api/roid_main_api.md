# roid_main API Reference

> **Source**: `src/thegent/roid_main.py`

Roid CLI: Factory Droid-backed interactive harness with dex/clode-style aliases.

## default_roid

Default roid behavior: flash model (gemini-3-flash).

```python
default_roid(ctx)
```

## install_links

