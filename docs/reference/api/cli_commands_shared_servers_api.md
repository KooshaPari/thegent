# cli_commands_shared_servers API Reference

> **Source**: `src/thegent/cli_commands_shared_servers.py`

CLI Commands for Shared Server Management

---

## shared_health

Check health of shared servers.

```python
shared_health(project_root)
```

---

## shared_scope

Show server scope (system-wide or project-scoped).

```python
shared_scope(project_root)
```

---

## shared_status

Show status of shared servers.

```python
shared_status(project_root)
```
