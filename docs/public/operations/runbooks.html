Runbooks ​

Use these short runbooks for common operational failures.

Runbook: Broken Shell Integration ​

  1. Regenerate shell config snippet:
bash
thegent shell-init zsh
  1. Ensure your shell startup file loads it.
  2. Reinstall shims:
bash
thegent install-shims
thegent doctor

Runbook: Credential/Auth Failure ​

  1. Re-run setup:
bash
thegent setup
  1. Re-test with explicit provider:
bash
thegent run "health check" --provider codex --debug

Runbook: Stuck Background Sessions ​

  1. Inspect sessions:
bash
thegent ps
  1. Stop problematic session:
bash
thegent stop <session_id>
  1. Restart with a narrower prompt or different provider.

Runbook: MCP Connectivity Failure ​

  1. Start MCP server:
bash
thegent serve
  1. Verify client target host/port.
  2. Remove stale resources safely:
bash
thegent mcp prune
