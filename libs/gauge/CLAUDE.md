# Gauge

Benchmarking and xDD test quality framework.

## Purpose

Provides benchmarking, property testing, mutation testing, contract verification, and reporting utilities.

## Architecture

- `benchmarking` for criterion-based benchmarks
- `property` for proptest strategies
- `mutation` for mutation testing
- `spec` for contract-based verification
- `reporters` for HTML/JSON output

## Build

```bash
cargo test
```
