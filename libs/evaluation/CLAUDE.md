# evaluation

**Evaluation framework and harness for testing and benchmarking.**

## Overview

Framework for running evaluations, benchmarks, and test harnesses across the Phenotype ecosystem.

## Architecture

Provides:
- Test harness infrastructure
- Benchmark runners
- Evaluation metrics collection
- Result reporting

## Build & Test

```bash
# Install
pip install -e .

# Test
pytest tests/

# Run evaluation
python -m evaluation --help
```
