# Migration Guide: Hexagonal Architecture

**Version**: 1.0.0
**Last Updated**: 2026-03-25

## Overview

This guide provides step-by-step instructions for migrating existing codebases to hexagonal (Ports & Adapters) architecture.

## Migration Strategy: Strangler Fig Pattern

We use the Strangler Fig pattern for incremental migration:

```
┌─────────────────────────────────────────────────────────────────┐
│                    Incremental Migration                          │
├─────────────────────────────────────────────────────────────────┤
│  Phase 1: Extract Domain (identify core business logic)          │
│       ↓                                                          │
│  Phase 2: Create Ports (define interfaces)                        │
│       ↓                                                          │
│  Phase 3: Build Adapters (implement infrastructure)               │
│       ↓                                                          │
│  Phase 4: Redirect Traffic (switch callers to new architecture) │
│       ↓                                                          │
│  Phase 5: Remove Legacy (delete old code)                         │
└─────────────────────────────────────────────────────────────────┘
```

## Phase 1: Identify Domain Logic

### Step 1.1: Audit Existing Code

```
# Find files with business logic (heuristics)
find src -name "*.rs" -o -name "*.py" -o -name "*.ts" | xargs grep -l "business|domain|entity" | head -20

# Find files with external dependencies
grep -r "use\|import\|require" src --include="*.rs" | grep -v "std::|crate::" | wc -l
```

### Step 1.2: Identify Domain Objects

Look for:
- Entities with identity (User, Order, Product)
- Value objects (Money, Email, Address)
- Domain services (calculation, validation)
- Domain events (OrderCreated, PaymentProcessed)

### Step 1.3: Extract Domain Module

```
# BEFORE: Mixed concerns
# user_service.py
class UserService:
    def create_user(self, email: str, password: str) -> User:
        # Validation mixed with business logic
        if not email:
            raise ValueError("Email required")
        if len(password) < 8:
            raise ValueError("Password too short")

        # Database access mixed in
        user = User(email=email, password_hash=hash(password))
        db.save(user)

        # External service call
        send_welcome_email(user)

        return user
```

```
# AFTER: Separated concerns
# domain/user.py
class User:
    def __init__(self, email: Email, password_hash: str):
        self.email = email
        self.password_hash = password_hash
        self.id = UserId.generate()

    @classmethod
    def create(cls, email: Email, password: PlainPassword) -> "User":
        password.validate()
        return cls(email=email, password_hash=password.hash())

# domain/errors.py
class DomainError(Exception):
    pass

class InvalidEmailError(DomainError):
    pass

class WeakPasswordError(DomainError):
    pass
```

## Phase 2: Define Ports

### Step 2.1: Create Inbound Ports (Use Cases)

```
# domain/ports/inbound/user_use_cases.py
from abc import ABC, abstractmethod
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from domain.entities import User
    from domain.value_objects import UserId, Email

class CreateUserUseCase(ABC):
    @abstractmethod
    async def execute(self, email: str, password: str) -> UserId:
        """Create a new user account."""
        ...

class GetUserUseCase(ABC):
    @abstractmethod
    async def execute(self, user_id: UserId) -> User:
        """Retrieve a user by ID."""
        ...
```

### Step 2.2: Create Outbound Ports (Infrastructure)

```
# domain/ports/outbound/user_repository.py
from abc import ABC, abstractmethod
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from domain.entities import User
    from domain.value_objects import UserId

class UserRepositoryPort(ABC):
    @abstractmethod
    async def save(self, user: User) -> None:
        """Persist a user."""
        ...

    @abstractmethod
    async def find_by_id(self, user_id: UserId) -> User | None:
        """Find a user by ID."""
        ...
```

## Phase 3: Build Adapters

### Step 3.1: Create Repository Adapter

```
# adapters/outbound/persistence/sqlalchemy_user_repository.py
from domain.ports.outbound import UserRepositoryPort
from domain.entities import User

class SQLAlchemyUserRepository(UserRepositoryPort):
    def __init__(self, session: Session):
        self.session = session

    async def save(self, user: User) -> None:
        db_user = DbUser(
            id=str(user.id),
            email=str(user.email),
            password_hash=user.password_hash,
        )
        self.session.add(db_user)
        await self.session.commit()

    async def find_by_id(self, user_id: UserId) -> User | None:
        db_user = await self.session.get(DbUser, str(user_id))
        if not db_user:
            return None
        return User.restore(
            id=UserId(db_user.id),
            email=Email(db_user.email),
            password_hash=db_user.password_hash,
        )
```

### Step 3.2: Create Application Service

```
# application/use_cases/create_user.py
from domain.ports.inbound import CreateUserUseCase
from domain.ports.outbound import UserRepositoryPort, EmailServicePort
from domain.value_objects import Email, PlainPassword, UserId
from domain.errors import InvalidEmailError, WeakPasswordError

class CreateUserService(CreateUserUseCase):
    def __init__(
        self,
        user_repository: UserRepositoryPort,
        email_service: EmailServicePort,
    ):
        self.user_repository = user_repository
        self.email_service = email_service

    async def execute(self, email: str, password: str) -> UserId:
        # Domain logic in application layer
        try:
            email_vo = Email.parse(email)
        except ValueError:
            raise InvalidEmailError(f"Invalid email: {email}")

        try:
            password_vo = PlainPassword.from_plain(password)
        except ValueError:
            raise WeakPasswordError("Password must be at least 8 characters")

        user = User.create(email=email_vo, password=password_vo)
        await self.user_repository.save(user)
        await self.email_service.send_welcome(user)

        return user.id
```

## Phase 4: Redirect Traffic

### Step 4.1: Create DI Container

```
# main.py
from adapters.outbound.persistence import SQLAlchemyUserRepository
from adapters.outbound.email import SendGridEmailAdapter
from application.use_cases import CreateUserService

def create_container() -> Container:
    container = Container()

    # Infrastructure
    container.register(UserRepositoryPort, SQLAlchemyUserRepository)
    container.register(EmailServicePort, SendGridEmailAdapter)

    # Application Services
    container.register(CreateUserUseCase, CreateUserService)

    return container
```

### Step 4.2: Wire Up Controllers

```
# adapters/inbound/api/users.py
from fastapi import APIRouter, Depends, HTTPException

router = APIRouter()

def get_create_user_use_case(
    container: Container = Depends(get_container),
) -> CreateUserUseCase:
    return container.resolve(CreateUserUseCase)

@router.post("/users", status_code=201)
async def create_user(
    request: CreateUserRequest,
    use_case: CreateUserUseCase = Depends(get_create_user_use_case),
) -> UserResponse:
    try:
        user_id = await use_case.execute(request.email, request.password)
        return UserResponse(id=str(user_id))
    except DomainError as e:
        raise HTTPException(status_code=400, detail=str(e))
```

## Phase 5: Remove Legacy

### Step 5.1: Verify No References

```
# Find references to old service
grep -r "OldUserService" src --include="*.py"
grep -r "from .user_service import" src --include="*.py"
```

### Step 5.2: Delete Old Code

```
# Remove old service file
rm src/old_user_service.py

# Remove old database models (if replaced)
rm src/models/user_model.py
```

## Migration Checklist

- [ ] Domain entities extracted with no external dependencies
- [ ] Value objects created for primitive types
- [ ] Domain errors defined
- [ ] Inbound ports (use cases) defined
- [ ] Outbound ports (repositories, services) defined
- [ ] Repository adapters implemented
- [ ] Application services implemented
- [ ] DI container configured
- [ ] Controllers wired to use cases
- [ ] Integration tests passing
- [ ] Old code removed
- [ ] Documentation updated

## Common Pitfalls

### 1. Leaking Dependencies to Domain

```
# BAD: Domain depends on external library
from sqlalchemy import Column, String

class User:  # Domain
    id = Column(String, primary_key=True)  # LEAKS SQLAlchemy!
```

```
# GOOD: Domain has no external dependencies
from dataclasses import dataclass
from domain.value_objects import UserId, Email

@dataclass
class User:  # Domain - Pure!
    id: UserId
    email: Email
```

### 2. Anemic Domain Model

```
# BAD: Domain objects are just data bags
class User:
    def __init__(self, data):
        self.data = data
```

```
# GOOD: Domain objects have behavior
class User:
    def change_email(self, new_email: Email) -> None:
        self.email = new_email
        self.events.append(EmailChangedEvent(...))
```

### 3. God Objects

```
# BAD: One class does everything
class UserService:
    def create_user(self): ...
    def update_user(self): ...
    def delete_user(self): ...
    def send_email(self): ...
    def generate_report(self): ...
    def backup_database(self): ...
```

```
# GOOD: Separated by concern
class CreateUserUseCase: ...
class UpdateUserUseCase: ...
class EmailService: ...
class ReportGenerator: ...
```

## Testing Strategy

### Unit Tests (Domain)

```
def test_user_cannot_change_email_to_invalid():
    user = User.create(valid_email, password)

    with pytest.raises(InvalidEmailError):
        user.change_email("not-an-email")
```

### Integration Tests (Adapters)

```
@pytest.mark.asyncio
async def test_user_persisted_and_retrieved():
    repo = SQLAlchemyUserRepository(session)
    user = User.create(valid_email, password)

    await repo.save(user)
    retrieved = await repo.find_by_id(user.id)

    assert retrieved == user
```

### Contract Tests (Ports)

```
# Tests verify adapters satisfy port contracts
def test_user_repository_satisfies_port():
    repo = SQLAlchemyUserRepository(session)
    assert isinstance(repo, UserRepositoryPort)
```
