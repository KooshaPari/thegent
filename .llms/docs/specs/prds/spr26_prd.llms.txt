## 7. Non-Functional Requirements

### NFR-1: CSE 535 A2 - MOBILE SECURITY (Post-Quantum Cryptography)

### Requirement 1: Parameter Selection

**What it means:**
- Choose secure n, q, σ for Learning with Errors problem
- Prevent known attacks: Gaussian elimination, BKZ lattice reduction
- Typical values: n=256-512, q=2^12-2^16, σ=√2-√8

**How we validate:**
```
Input: Security level (128, 192, 256-bit)
Output: (n, q, σ) parameters

Example:
  Security=128 bits → (n=256, q=2^13, σ=√2.7)
  Security=256 bits → (n=512, q=2^16, σ=√4.0)

Check:
- n is power of 2: ✓
- q is prime or 2^k: ✓
- σ provides c

A = np.array([[1, 6, 6, 2], [6, 0, 5, 3], [2, 5, 4, 1]])

### Encryption
```
public_key = (A, np.array([4, 0, 5]))
random_vector = np.array([1, 0, 1])

u0, v0 = encrypt(public_key, random_vector, 0, 7)
assert np.array_equal(u0, np.array([3, 4, 3, 3]))
assert v0 == 2

u1, v1 = encrypt(public_key, random_vector, 1, 7)
assert np.array_equal(u1, np.array([3, 4, 3, 3]))
assert v1 == 5
