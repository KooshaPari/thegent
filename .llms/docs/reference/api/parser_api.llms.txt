# parser API Reference

> **Source**: `src/thegent/task/parser.py`

Task parsing implementation.

---

## TaskParseError

Error parsing task file.

**Inherits from**: `Exception`

---

## detect_task_format

```
detect_task_format(content: str)
```

Auto-detect task format.

**Parameters**:

- `content`: File content

**Returns**: Format type: 'yaml_frontmatter', 'legacy', 'json', or 'unknown'

---

## extract_markdown_sections

```
extract_markdown_sections(body: str)
```

Extract markdown sections by header.

**Parameters**:

- `body`: Markdown body content

**Returns**: Dictionary mapping section names to content

---

## parse_legacy_task

```
parse_legacy_task(content: str)
```

Parse legacy task format (backward compatibility).

**Parameters**:

- `content`: Legacy task content

**Returns**: Parsed task dictionary

---

## parse_list_from_markdown

```
parse_list_from_markdown(content: str)
```

Parse bullet list from markdown content.

**Parameters**:

- `content`: Markdown content with bullet list

**Returns**: List of strings

---

## parse_markdown_sections_to_fields

```
parse_markdown_sections_to_fields(body: str, frontmatter: dict[(str, Any)])
```

Parse markdown sections into structured task fields.

**Parameters**:

- `body`: Markdown body content
- `frontmatter`: Parsed frontmatter dictionary

**Returns**: Updated task dictionary with parsed markdown sections

---

## parse_steps_from_markdown

```
parse_steps_from_markdown(content: str)
```

Parse numbered steps from markdown content.

**Parameters**:

- `content`: Markdown content with numbered steps

**Returns**: List of step dictionaries

---

## parse_task_file

```
parse_task_file(file_path: Path)
```

Parse a task file (auto-detects format).

**Parameters**:

- `file_path`: Path to task file

**Returns**: Parsed task dictionary

**Raises**:

- `TaskParseError`: If file cannot be parsed

---

## parse_yaml_frontmatter

```
parse_yaml_frontmatter(content: str)
```

Parse YAML frontmatter from markdown content.

**Parameters**:

- `content`: Markdown content with YAML frontmatter

**Returns**: Tuple of (frontmatter_dict, markdown_body)

**Raises**:

- `ValueError`: If frontmatter is invalid or missing
