# skills API Reference

> **Source**: `src/thegent/cli/apps/skills.py`

Skills management CLI commands.

---

## skills_list

```
skills_list(json_output: bool)
```

List all available skills with their metadata.

---

## skills_select

```
skills_select(name: str)
```

Validate a skill name for run-time selection via --skill.

---

## skills_show

```
skills_show(name: str)
```

Show detailed information about a specific skill.

---

## skills_validate

```
skills_validate(name: str)
```

Validate a skill and show any errors or warnings.
