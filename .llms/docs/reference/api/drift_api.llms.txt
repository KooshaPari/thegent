## DriftDetector

Detects drift in policy state and cleans up stale overrides.

#### DriftDetector.detect_drift

```
detect_drift(self: Any)
```

Returns a report of detected issues.

---

#### DriftDetector.sweep

```
sweep(self: Any)
```
