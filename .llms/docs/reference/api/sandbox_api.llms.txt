WP-31002: Containerized Agent Sandboxes (Wasm).

Provides lightweight, secure execution environments for untrusted agent code using WebAssembly.
Ensures near-native performance with strict memory and capability isolation.

## WasmSandbox

Manages secure execution of agent code in a Wasm environment using Extism.

This class provides a higher-level interface for running Wasm binaries
with resource limits, timeout handling, and graceful fallback support.

### Methods

#### WasmSandbox.__init__

```

```

---

#### WasmSandbox.is_available

```

```

---

#### WasmSandbox.run_function

```
run_function(self: Any, wasm_binary_path: str, function_name: str, input_data: Any, fallback_fn: Any)
```

Execute a function inside the Wasm sandbox using Extism.

If Extism is not available and a fallback function is provided,
the fallback will be used instead.

**Parameters**:

- `wasm_binary_path`: Path to the Wasm binary file.
- `function_name`: Name of the function to call in the Wasm module.
- `input_data`: Input data to pass to the function.
- `fallback_fn`: Optional fallback function to use if Wasm fails.

**Returns**: Dictionary containing status, result/error, and timing information.
