# auto_install API Reference

> **Source**: `src/thegent/lsp/auto_install.py`

Auto-installation and auto-configuration for LSP servers and IDE integrations.

---

## auto_install_all_lsp_servers

```
auto_install_all_lsp_servers(auto_confirm: bool, skip_installed: bool)
```

Auto-install all available LSP servers.

**Parameters**:

- `auto_confirm`: Auto-confirm installation prompts
- `skip_installed`: Skip servers that are already installed

**Returns**: Dict mapping language to installation success status

---

## auto_install_lsp_server

```
auto_install_lsp_server(language: str, auto_confirm: bool)
```

Auto-install LSP server for language.

**Parameters**:

- `language`: Language name (python, typescript, etc.)
- `auto_confirm`: Auto-confirm installation prompts

**Returns**: True if installation succeeded or already installed, False otherwise

---

## check_command_available

```
check_command_available(command: str)
```

Check if a command is available in PATH.

Also checks common installation paths for Go tools (GOPATH/bin).

---

## ensure_lsp_server_installed

```
ensure_lsp_server_installed(language: str, auto_install: bool)
```

Ensure LSP server is installed, auto-installing if needed.

**Parameters**:

- `language`: Language name
- `auto_install`: Auto-install if missing

**Returns**: True if server is available, False otherwise
