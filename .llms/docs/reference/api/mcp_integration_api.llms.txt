# mcp_integration API Reference

> **Source**: `src/thegent/skills/mcp_integration.py`

MCP integration for skills auto-discovery.

This module provides MCP tools for listing, getting, and running skills.

---

## get_skill

```
get_skill(skill_name: str)
```

Get detailed information about a specific skill.

**Parameters**:

- `skill_name`: Name of the skill to retrieve.

**Returns**: JSON string with skill details and content.

---

## list_skills

List all available skills.

**Returns**: JSON string containing list of skills with their metadata.

---

## run_skill

```
run_skill(skill_name: str, context: Any)
```

Execute a skill with optional context.

**Parameters**:

- `skill_name`: Name of the skill to execute.
- `context`: Optional context for skill execution.

**Returns**: JSON string with execution result.

---

## validate_skill_tool

```
validate_skill_tool(skill_name: str)
```

Validate a skill by name.

**Parameters**:

- `skill_name`: Name of the skill to validate.

**Returns**: JSON string with validation results.
