
---

#### ReflectionRollbackStore.list_entries

```
list_entries(self: Any)
```

Get all recorded rollback entries.

**Returns**: List of RollbackEntry records in insertion order.

---

#### ReflectionRollbackStore.record

```
record(self: Any, entry_id: str, snapshot: dict[(str, Any)])
```

Record a new rollback entry.

**Parameters**:

- `entry_id`: Unique identifier for this rollback entry.
- `snapshot`: Dictionary containing the snapshot data.

**Returns**: The created RollbackEntry.

---

#### ReflectionRollbackStore.rollback_to

```
rollback_to(self: Any, entry_id: str)
```

Rollback to a previously recorded entry.

**Parameters**:

- `entry_id`: Unique identifier of the entry to rollback to.

**Returns**: The snapshot dictionary from that entry.
