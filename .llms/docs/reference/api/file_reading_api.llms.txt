# file_reading API Reference

> **Source**: `src/thegent/utils/file_reading.py`

Use offset/limit for targeted file reading.

---

## EfficientFileReader

Efficient file reading with offset/limit.

### Methods

#### EfficientFileReader.read_chunk

```
read_chunk(self: Any, file_path: Path, offset: int, limit: int)
```

Read a chunk of file.

**Parameters**:

- `file_path`: File to read
- `offset`: Byte offset
- `limit`: Maximum bytes to read

**Returns**: File chunk content

---

#### EfficientFileReader.read_lines

```
read_lines(self: Any, file_path: Path, start_line: int, num_lines: int)
```

Read specific lines from file.

**Parameters**:

- `file_path`: File to read
- `start_line`: Starting line number
- `num_lines`: Number of lines to read

**Returns**: List of lines
