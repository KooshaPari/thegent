# thegent CLI Reference

Complete reference for the `thegent` command-line interface.

## Overview

thegent is a unified agent orchestration system. It provides a single entry point
for spawning, controlling, and coordinating AI agents across providers, managing
sessions, planning work via DAG-based roadmaps, and enforcing governance policies.

```
thegent [--version] [--help] <command> [<subcommand>] [options]
```

All commands print `--help` output when invoked without required arguments. Rich
terminal output is the default; most commands accept `--format json` for machine
consumption.

---

## Global Flags

| Flag | Description |
|------|-------------|
| `--version` | Print the installed thegent version and exit. |
| `--help` | Show help for any command or subcommand. |
| `--install-completion` | Install shell completion for the active shell. |
| `--show-completion` | Print shell completion script to stdout. |

## Top-Level Shortcut Commands

These commands are available directly on the root `thegent` invocation as
convenience aliases for common workflows.

### thegent do

Quick-run a prompt with the default configured agent.

```
thegent do <prompt>
```

**Arguments**

| Argument | Description |
|----------|-------------|
| `prompt` | The prompt text to send to the agent. Required. |

**Examples**

```
thegent do "Summarize the open issues in this repository"
thegent do "Refactor the auth module to use hexagonal architecture"
```

---

### thegent setup

Run the interactive setup wizard and configure providers, API keys, and system
integrations.

```
thegent setup [options]
```

**Options**

| Option | Description |
|--------|-------------|
| `--api-key TEXT` | NVIDIA NIM API key. |
| `--model TEXT` | NVIDIA NIM model override. |
| `--openrouter-key TEXT` | OpenRouter API key. |
| `--kilo-key TEXT` | Kilo.ai API key. |
| `--zai-key TEXT` | Z.AI (Zhipu) API key. |
| `--minimax-key TEXT` | MiniMax API key. |
| `--wizard / --no-wizard` | Run the interactive wizard (default: on). |
| `--links / --no-links` | Install `claudeglm` / `claudemax` shell shortcuts. |
| `--hooks / --no-hooks` | Install git hooks (pre-commit, pre-push) into `.git/hooks`. |
| `--skills / --no-skills` | Sync thegent-skills template to `~/.claude`, `~/.cursor`, and project. |
| `--harness / --no-harness` | Install or update the heliosShield harness. |
| `--full` | Full setup: run all install steps, shim installation, lock-cleanup service, MCP service, and harness. |
| `--agents TEXT` | Comma-separated list of agents to configure (e.g. `claude,codex,cursor`). Skips unconfigured agents in wizard. |

**Examples**

```
thegent setup
thegent setup --full
thegent setup --agents claude,codex --no-wizard
```

## thegent run

Execute agent tasks, manage background sessions, and inspect run history.

```
thegent run <subcommand> [options]
```

### thegent run agent

Run an agent task interactively or in the foreground.

```
thegent run agent <prompt> [options]
```

**Options**

| Option | Description |
|--------|-------------|
| `--agent TEXT` | Agent name: `claude`, `openai`, `gemini`, `codex`, and others. |
| `--model TEXT` | LLM model override (e.g. `sonnet`, `opus`, `gpt-4o`). |
| `--cd PATH` | Working directory for the agent to operate in. |
| `--timeout INT` | Maximum execution time in seconds. |
| `--skill TEXT` | Activate a named skill. Repeatable. |
| `--routing TEXT` | Routing strategy override. |
| `--failover` | Enable automatic provider failover. |

**Examples**

```
thegent run agent "Add unit tests to the payment module" --agent claude
thegent run agent "Fix the failing CI job" --agent codex --model codex-default
thegent run agent "Refactor this service" --cd ./services/auth --skill hexagonal
```

### thegent run bg

Run an agent task in the background and return immediately. The run is tracked
as a session.

```
thegent run bg <prompt> [options]
```

**Options**

| Option | Description |
|--------|-------------|
| `--agent TEXT` | Agent name. |
| `--model TEXT` | LLM model override. |
| `--cd PATH` | Working directory. |
| `--timeout INT` | Maximum execution time in seconds. |
| `--run-id TEXT` | Assign a stable run identifier. |
| `--task-id TEXT` | Associate with a DAG task ID. |
| `--lane TEXT` | Execution lane for multi-lane queuing. |
| `--skill TEXT` | Activate a named skill. Repeatable. |
| `--routing TEXT` | Routing strategy override. |
| `--failover` | Enable provider failover. |
| `--speculative` | Run speculatively without committing changes. |
| `--idempotency-token TEXT` | Deduplicate repeated submissions. |

**Examples**

```
thegent run bg "Migrate the database schema" --agent claude --task-id T-42
thegent run bg "Run the full test suite" --lane slow --timeout 600
```

### thegent run history

**Options**

| Option | Description |
|--------|-------------|
| `--limit INT` | Maximum entries to display (default: 20). |

## thegent session

Inspect and resume background agent sessions.

```
thegent session <subcommand> [options]
```

### thegent session list

List all sessions with status information.

```
thegent session list [options]
```

**Options**

| Option | Description |
|--------|-------------|
| `--all` / `-a` | Show sessions from all owners, not just the current user. |
| `--owner TEXT` / `-o` | Filter by owner tag. |
| `--format TEXT` / `-F` | Output format: `rich` or `json` (default: `rich`). |
| `--limit INT` / `-n` | Maximum sessions to return (default: 50). |

**Examples**

```
thegent session list
thegent session list --all --format json
thegent session list --owner agent-1 --limit 10
```

### thegent session resume

Resume a previously created session using the stable state contract.

```
thegent session resume [<session-id>] [options]
```

**Arguments**

| Argument | Description |
|----------|-------------|
| `session-id` | Session ID to resume. Defaults to the latest resumable session if omitted. |

**Options**

| Option | Description |
|--------|-------------|
| `--prompt TEXT` | Optional follow-up prompt to queue after resume. |
| `--skill TEXT` | Activate a named skill on resume. Repeatable. |

**Examples**

```
thegent session resume
thegent session resume sess-abc123 --prompt "Now run the tests"
thegent session resume sess-abc123 --skill hexagonal
```

```
thegent crew create [options]
```

**Options**

| Option | Description |
|--------|-------------|

## thegent session-contract-health-gate

Evaluate the session contract health gate against a minimum-healthy-ratio
threshold. Exits non-zero if the threshold is not met (suitable for CI gates).

```
thegent session-contract-health-gate [options]
```

**Options**

| Option | Description |
|--------|-------------|
| `--all` / `-a` | Include sessions from all owners. |
| `--owner TEXT` / `-o` | Owner tag filter. |
| `--strict` | Strict health-check mode. |
| `--format TEXT` / `-f` | Output format: `rich`, `json`, or `md` (default: `rich`). |
| `--min-healthy-ratio FLOAT` | Minimum healthy ratio threshold (default: `1.0`). |
| `--policy-profile TEXT` | Health policy profile name. |
| `--no-worse-than-baseline` | Fail if health has regressed compared to baseline. |
| `--regression-tolerance FLOAT` | Allowed regression tolerance (default: `0.0`). |
| `--output PATH` | Export report to a file. |
| `--export-format TEXT` | Export format override. |
| `--overwrite` | Overwrite an existing export file. |

## Agent Names

| Agent | Flag Value | Notes |
|-------|-----------|-------|
| Claude (Anthropic) | `claude` | Requires `ANTHROPIC_API_KEY`. |
| OpenAI GPT | `openai` | Requires `OPENAI_API_KEY`. |
