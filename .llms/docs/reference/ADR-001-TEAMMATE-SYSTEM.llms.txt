# ADR-001: Teammate Subagent System

## Status

Accepted

## Context

Need a way to delegate tasks to specialized AI agents (teammates) for parallel execution and task routing.

## Decision

Implement a teammate subagent system with:

1. **Auto-discovery**: Scan `agents/` directory for teammate definitions
2. **Delegation Protocol**: XML-based handoff for structured task assignment
3. **Priority Support**: CRITICAL/HIGH/NORMAL/LOW priority levels
4. **Async Execution**: Non-blocking task delegation with status tracking
5. **Timeout Handling**: Configurable timeouts with exponential backoff

## Architecture

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────┐
│   CLI/API   │────▶│    Delegate      │────▶│  Teammate   │
└─────────────┘     │  (orchestrator)  │     │  (agent)    │
                    └──────────────────┘     └─────────────┘
                           │
                           ▼
                    ┌──────────────────┐
                    │    Registry      │
                    │  (discovery)     │
                    └──────────────────┘
```

## Implementation

- `src/thegent/teammates/registry.py` - Teammate discovery and management
- `src/thegent/teammates/delegate.py` - Task delegation with XML handoff
- `src/thegent/teammates/status.py` - Status tracking

## Consequences

- Positive: Enables parallel task execution, specialized agents
- Negative: Adds complexity, requires teammate configuration
