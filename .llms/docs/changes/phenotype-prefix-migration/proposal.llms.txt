# Proposal: `phenotype-*` prefix migration (neutral names)

## Context

`PACKAGE_REPO_NAMING_TAXONOMY.md` reserves **`phenotype-*`** for org-bound surfaces. Several repositories use the prefix for **generic** libraries (hex kits, crypto, resilience, metrics). Renames reduce confusion and improve reuse outside the org.

## Goals

1. Complete **Wave 0** hygiene (READMEs, buildability of stubs).
2. Record **decision-ready** ADRs for repo/crate renames without executing GitHub renames in this change (high-churn, owner approval).
3. Keep a **single inventory** aligned with `Phenotype/repos/phenotype-*` directories.

## Non-goals

- Mass `git filter-repo` or GitHub renames without a reviewed runbook (when executing renames, use **`GITHUB_RENAME_RUNBOOK.md`**).

- Changing published crate names on crates.io without a semver and deprecation plan.
