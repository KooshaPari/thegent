## Executive readout

The prior parity and QOL docs are directionally strong, but some high-priority items are now implemented and several recommendations are stale. The next highest-value work is not broad redesign; it is tightening UX consistency, closing a few feature stubs, and reducing parity-doc drift so feature decisions stay accurate.

## Live gaps worth fixing next

### P0: Command-surface polish and trust consistency

1. `team` stream still exposes placeholder commands that print "not yet implemented".
   - Evidence: `src/thegent/cli/apps/team.py` (`list`, `hierarchy`, `crew`).
   - Impact: weakens confidence in teammate feature surface.
   - Recommendation:
     - Either implement minimal real output (read from teammate registry/state), or
     - hide these commands behind `hidden=True` until implemented.

2. Welcome panel misses key onboarding commands users actually need first.
   - Evidence: callback panel in `src/thegent/cli/apps/main.py` currently highlights `run/sync/audit/plan`, but not `setup`/`doctor`.
   - Recommendation:
     - Add `setup` and `doctor` explicitly.
     - Include one line for teammate workflow entrypoint (`team teammates list`).

### P1: Parity verification quality

1. AGENTS/CLAUDE parity verification is format-focused, not rule-semantic.
   - File: `docs/governance/AGENTS_CLAUDE_PARITY_VERIFICATION.md`.
   - Recommendation:
     - Add automated semantic checks for critical rule blocks (hash section bodies, not line ranges).
     - Add CI test to fail if critical rule bodies diverge.

2. Cross-language Rust/Python parity still deferred by skipped extension build path.
   - File: `docs/reports/2026-02-21-B90-W3-B2-parity-gap-report.md`.
   - Recommendation:
     - Promote `maturin develop --release` parity job to required for parser-touching changes.
     - Convert skip-based tests into fail-on-missing-extension in CI profile.

### P1: Doc-source consolidation

1. Fragmentation (`docs/fragemented/*`) duplicates high-signal parity docs.
   - Impact: stale recommendations persist and conflict with reality.
   - Recommendation:
     - Define canonical source list for parity/QOL docs.
     - Add a doc-lint check to detect duplicate titled reports in fragmented and canonical trees.
