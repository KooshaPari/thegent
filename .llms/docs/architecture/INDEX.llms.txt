# Architecture Documentation Index

## Overview

The Phenotype ecosystem follows **Hexagonal Architecture** (Ports & Adapters) with **Clean Architecture** principles.

| Pattern | Description | Reference |
|---------|-------------|-----------|
| **Hexagonal** | Domain isolation via ports/adapters | ADR-003 |
| **Clean Architecture** | Layered separation (Domain → Application → Adapters) | ADR-003 |
| **Event-Driven** | Async messaging via event bus | ADR-006 |
| **Plugin Architecture** | Dynamic extension loading | ADR-013 |
| **xDD Methodologies** | TDD, BDD, DDD, SDD, ADD, CQRS | rolling-hand-rules.md |

## Hexagonal Architecture

### Layers

```
┌─────────────────────────────────────────────┐
│                   Adapters                     │
│  ┌──────────────┐    ┌──────────────────┐  │
│  │ Inbound (API) │    │ Outbound (Cache) │  │
│  └───────┬──────┘    └────────┬─────────┘  │
│          │                      │              │
│  ┌───────▼────────────────────▼─────────┐  │
│  │              Ports (Interfaces)         │  │
│  │    InboundPort    │    OutboundPort   │  │
│  └───────────────────┼───────────────────┘  │
│                      │                        │
│  ┌──────────────────▼───────────────────┐  │
│  │              Application               │  │
│  │         (Use Cases / Services)        │  │
│  └───────────────────┬───────────────────┘  │
│                      │                        │
│  ┌──────────────────▼───────────────────┐  │
│  │                 Domain                │  │
│  │      (Entities, Value Objects)        │  │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

### Ports Definition

**Inbound Ports** (driven by application):
- `SkillLoaderPort` - Load skill from registry
- `TaskExecutorPort` - Execute task with context
- `ResearchEnginePort` - Query research corpus

**Outbound Ports** (driven by infrastructure):
- `CachePort` - Read/write cache
- `PersistencePort` - Store aggregates
- `EventBusPort` - Publish domain events
- `ConfigPort` - Load configuration
