# DAG / WBS

## Phase 0 - Stabilize Authority Boundaries
1. Freeze `src/thegent` vs `packages/thegent-*` duplication growth.
2. Choose authoritative tree per bounded context.
3. Add CI gates that fail on mirrored-file divergence for extracted domains.
4. Remove new feature work from non-authoritative mirrors.

## Phase 1 - Extract Lowest-Risk Package Repos
1. `thegent-protocols`
2. `thegent-sync`
3. `thegent-audit`
4. `thegent-planning`

Dependency order:
- `thegent-protocols` first because MCP/JSON-RPC contracts are consumed broadly.
- `thegent-sync` after protocols because board/adapter contracts should depend on stable protocol/core interfaces.
- `thegent-audit` and `thegent-planning` can proceed in parallel once shared contracts are fixed.

## Phase 2 - Shrink CLI Monolith
1. Extract `cli/apps/*` into command-group packages with one authoritative tree.
2. Move governance, audit, sync, planning, and session commands behind package entrypoints.
3. Leave only argument parsing and orchestration composition in the root CLI.
4. Delete mirrored command implementations from `src/thegent` after parity validation.

## Phase 3 - Separate Runtime Services
1. `thegent-agent-runtime` microservice for long-lived provider / session execution.
2. `thegent-syncd` plugin microservice for GitHub/Linear/project-board synchronization.
3. `thegent-mcp-gateway` plugin microservice for MCP and JSON-RPC transport hosting.
4. `thegent-auditd` service for event/audit ingestion where centralization is required.

## Phase 4 - Isolate Native Subsystems
1. Keep `thegent-hooks` as its own repo or at minimum its own releaseable crate workspace.
2. Keep `thegent-shm` as its own low-level systems repo/crate workspace.
3. Isolate `thegent-shims` and runtime bridge crates from application-layer Python code.
4. Publish typed interfaces consumed by Python packages instead of cross-tree ad hoc imports.

9. Extract GitHub board adapter into `thegent-sync` adapter package.
10. Extract Linear adapter into `thegent-sync` adapter package.
11. Extract autosync status contract into stable schema module.
