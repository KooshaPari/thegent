# Forge — headless agent (team defaults)

This guide mirrors the canonical Claude skill at **`~/.claude/skills/forge-agent/SKILL.md`** on your workstation. If paths differ, treat this file as the **in-repo** copy for onboarding; the skill file is the source of truth for automation.

## What Forge is

**Forge** (`forge`) is the **primary headless CLI** for scripted, non-interactive agent work. It exposes multiple providers (Claude Code, Codex, Copilot, Minimax, etc.) behind one binary.

## Native invocation

```
forge -p "Task description" -C /path/to/repo
forge -p "Task" --model <model-id>
```

Use `forge list model`, `forge list provider`, `forge doctor` to discover IDs on your machine.

## Team model defaults

| Role | Route | Model (intent) |
|------|--------|----------------|
| Default | Minimax | `m2.7-highspeed` |
| Cheap | Copilot | `gpt-5-mini` |
| High (long) | Codex ↔ Claude | **Round‑robin:** GPT‑5.4 high (Codex) and Claude Opus 4.6 — alternate `--model` between invocations when context is tight |

## GLM

**Not used** in team defaults. Do not remove GLM provider code from **CliproxyAPI++**; this is a **workflow** choice only.

## vs thegent

- **Forge:** `forge -p` — headless, no cliproxy/thegent required for simple runs.
- **thegent:** orchestration, work stream, `bg`, Sitback — see project `CLAUDE.md` / `AGENTS.md`.
