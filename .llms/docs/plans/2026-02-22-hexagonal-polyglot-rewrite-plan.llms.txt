# thegent Hexagonal Split + Full Polyglot Rewrite Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Simultaneously split thegent into 4 hexagonal sub-projects and rewrite all non-orchestration Python to Rust/Zig/Go, reducing Python from 74% → ≤25% of LOC with zero feature regression.

**Architecture:** Four parallel tracks execute simultaneously (not incrementally): CLIProxy absorbs all LLM routing/auth, Rust rewrites governance/session/audit/metrics, Zig replaces all shell hook scripts, and the monolith splits into thegent-cli / thegent-agents / thegent-mcp sub-projects. All sub-projects communicate exclusively via MCP protocol. FastMCP 3.x stays as the MCP server frontend (not replaced by Rust MCP SDK).

**Tech Stack:** Python (FastMCP 3.x, Typer, Textual), Rust (PyO3, maturin, existing 21 crates), Zig (pinned stable, WASM-compilable), Go (CLIProxyAPI++ v6), MCP protocol, uv workspaces

**Design doc:** `docs/plans/2026-02-22-hexagonal-polyglot-rewrite-design.md`

**T3B.6 — Hypothesis property test for Pareto routing**

```
# tests/test_routing_properties.py
from hypothesis import given, strategies as st
from thegent.routing.pareto import ParetoRouter

@given(
    providers=st.lists(
        st.fixed_dictionaries({
            "model": st.text(min_size=1),
            "cost": st.floats(min_value=0.001, max_value=1.0),
            "latency_ms": st.integers(min_value=100, max_value=10000),
            "quality": st.floats(min_value=0.5, max_value=1.0),
        }),
        min_size=2, max_size=10
    ),
    max_cost=st.floats(min_value=0.01, max_value=1.0),
)
def test_pareto_never_selects_dominated_model(providers, max_cost):
    """Selected model must not be dominated by any other model."""
    router = ParetoRouter(providers)
    selected = router.select(max_cost_per_call=max_cost)
    if selected is None:
        return  # no feasible solution is valid
    for p in providers:
        if p["model"] == selected["model"]:
            continue
        dominated = (
            p["cost"] <= selected["cost"] and
            p["latency_ms"] <= selected["latency_ms"] and
            p["quality"] >= selected["quality"] and
            (p["cost"] < selected["cost"] or
             p["latency_ms"] < selected["latency_ms"] or
             p["quality"] > selected["quality"])
        )
        assert not dominated, f"Selected {selected} is dominated by {p}"
```
