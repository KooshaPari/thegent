# thegent Monorepo Decomposition Plan

**Date**: 2026-03-25
**Status**: Draft
**Version**: 1.0

---

## Executive Summary

Decompose thegent monorepo (34 Rust crates + 17 Python packages + 198 modules) into independently versioned, deployable micro-repos following KISS, DRY, SOLID, and Clean Architecture principles.

## Decomposition Strategy

### Principles

1. **Single Responsibility**: Each repo does one thing well
2. **Independence**: No circular dependencies between repos
3. **Polyglot**: Each repo uses optimal language for its domain
4. **Versioning**: Independent versioning per repo
5. **Shared Core**: Extract shared primitives to dedicated libs

### Dependency Graph (Target)

```
                    ┌─────────────────────────────────────────┐
                    │           thegent-core (shared)          │
                    │   - SHM, Cache, Metrics, Utils, FSM     │
```

## Dependency Management

### PyO3 Bindings Strategy

For Python/Rust interop, use PyO3 bindings:

```
# Python package Cargo.toml
[lib]
name = "thegent_shm"
crate-type = ["cdylib"]

[dependencies]
pyo3 = { version = "0.22", features = ["extension-module"] }
```

### Workspace Structure

```
# Recommended workspace for Rust repos
packages:
  - path: crates/thegent-shm
  - path: crates/thegent-cache
  - path: crates/thegent-subprocess
  # etc.
```
