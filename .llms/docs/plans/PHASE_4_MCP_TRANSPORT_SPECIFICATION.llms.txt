## Executive Summary

Phase 4 adds real-time synchronization to the civilization framework via MCP (Model Context Protocol). Currently, the registry is file-based with in-memory caching. Phase 4 introduces streaming heartbeats, reactive updates, and cross-civilization agent communication.

### Implementation Details

#### 4B.1: Heartbeat Streaming
```
# In CivilizationMCPServer

class HeartbeatStream:
    """Real-time heartbeat streaming."""

    def __init__(self, registry: GlobalAgentRegistry):
        self.registry = registry
        self.subscribers = set()  # Connected clients

    async def stream_heartbeats(self):
        """Stream heartbeats at 1 Hz."""
        while True:
            heartbeats = self.registry.get_active_agents()
            await self.broadcast({
                "type": "heartbeats",
                "timestamp": time.time(),
                "agents": heartbeats
            })
            await asyncio.sleep(1)

    async def broadcast(self, message):
        """Broadcast to all subscribers."""
        for client in self.subscribers:
            try:
                await client.send(message)
            except Exception as e:
                self.subscribers.discard(client)
```

#### 4B.2: Registry Change Notifications
```
class RegistryNotifier:
    """Notify clients of registry changes."""

    def __init__(self, registry: GlobalAgentRegistry):
        self.registry = registry
        self.subscribers = set()

    def on_agent_registered(self, agent_id: str):
        """Notify subscribers of new agent."""
        self.broadcast({
            "type": "agent_registered",
            "agent_id": agent_id,
            "timestamp": time.time()
        })

    def on_agent_unregistered(self, agent_id: str):
        """Notify subscribers of removed agent."""
        self.broadcast({
            "type": "agent_unregistered",
            "agent_id": agent_id,
            "timestamp": time.time()
        })

    def on_heartbeat_updated(self, agent_id: str):
        """Notify subscribers of heartbeat update."""
        self.broadcast({
            "type": "heartbeat_updated",
            "agent_id": agent_id,
            "timestamp": time.time()
        })
```

#### 4B.3: Integration into SwarmController
```
class SwarmController:
    def __init__(self):
```

## Phase 4C: Cross-Civilization Communication

### Objectives
1. Implement agent-to-agent messaging protocol
2. Enable L1-to-L1 civilization coordination
3. Add message routing and acknowledgment
4. Support broadcast and direct messaging

### Implementation Details

#### 4C.1: Message Broker
```
class AgentMessageBroker:
    """Broker for inter-agent messages."""

    def __init__(self, registry: GlobalAgentRegistry):
        self.registry = registry
        self.message_queue = asyncio.Queue()
        self.routes = {}  # agent_id -> handler

    async def send_message(self,
                          from_agent: str,
                          to_agent: str,
                          message_type: str,
                          payload: dict) -> bool:
        """Send message to agent."""
        msg = {
            "id": uuid4().hex[:8],
            "from": from_agent,
            "to": to_agent,
            "type": message_type,
            "payload": payload,
            "timestamp": time.time(),
            "ack": False
        }

        # Route message
        if to_agent == "broadcast":
            return await self.broadcast_message(msg)
        else:
            return await self.direct_message(msg)

    async def broadcast_message(self, msg):
        """Broadcast to all agents in project."""
        project = msg["from"].split(":")[0]
        agents = self.registry.get_agents_by_project(project)

        for agent in agents:
            if agent.agent_id != msg["from"]:
                await self.route_message(msg, agent.agent_id)

        return True

    async def direct_message(self, msg):
        """Route to specific agent."""
        await self.route_message(msg, msg["to"])
        # Wait for ACK (timeout 5s)
        return await self.wait_for_ack(msg["id"])
```

#### 4C.2: Message Types

| Type | Direction | Purpose | Example |
|------|-----------|---------|---------|
| `heartbeat_request` | L2→L1 | Request confirmation | Health check |
| `status_query` | L1→L2 | Ask for status | "What's your load?" |
| `task_assignment` | L1→L2 | Assign work | "Run test suite" |
| `result_report` | L2→L1 | Report completion | "Tests passed" |
| `error_alert` | L2→L1 | Alert to error | "Agent X is stale" |
| `coordination` | L1→L1 | Cross-civilization | "Merge registries" |
| `broadcast` | L1/L2→All | Notify all agents | "Shutdown in 60s" |

#### 4C.3: Message Format
```
@dataclass
class AgentMessage:
    id: str              # Unique message ID (uuid[:8])
    from_agent: str      # Sender agent ID
    to_agent: str        # Recipient (or "broadcast")
    type: str            # Message type
    payload: dict        # Message data
    timestamp: float     # Unix timestamp
    ack: bool            # Acknowledged?
    ack_timestamp: float # ACK time (optional)
```
