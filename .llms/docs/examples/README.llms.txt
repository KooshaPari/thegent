# VitePress Examples

This directory contains example pages demonstrating VitePress rich documentation features.

## Examples

- [mermaid-example.md](./mermaid-example.md) - Mermaid diagram examples
- [code-playground-example.md](./code-playground-example.md) - CodePlayground component examples
- [demo-gif-example.md](./demo-gif-example.md) - DemoGif component examples
- [math-emoji-example.md](./math-emoji-example.md) - Math rendering and emoji support
- [tooltip-example.md](./tooltip-example.md) - Tooltip component usage

## Usage

These examples can be referenced when creating new documentation pages. They demonstrate:

- How to use Mermaid diagrams
- How to embed CodePlayground components
- How to display demo GIFs
- How to use math equations (KaTeX)
- How to use emojis
- How to add tooltips
- Best practices for documentation
