## Overview

AgilePlus is the Phenotype project management platform. It provides spec-first development workflows, AI-driven task generation, and full traceability from requirements to code — closing the loop between product specs and implementation artifacts.

## Tech Stack

- **Frontend**: React, Next.js
- **Runtime**: Node.js / Bun
- **Port**: 4000
- **Styling**: Tailwind CSS + Radix UI

## Key Features

- Spec-first workflow: requirements drive tasks, tasks drive code
- AI-generated work breakdown structures from PRDs
- Full traceability matrix linking FRs to test functions
- Dashboard with real-time agent activity monitoring
- Evidence bundle gallery for auditing AI-generated work

## Quick Start

```bash
# Clone and install
git clone https://github.com/KooshaPari/AgilePlus
cd AgilePlus
bun install

# Run dev server
bun dev

# Build for production
bun run build
```
