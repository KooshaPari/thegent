## Overview

heliosApp is the primary UI for the Phenotype AI coding platform. Built with SolidJS and Bun for a fast, reactive interface with real-time collaboration support.

## Stack

- **Frontend**: SolidJS
- **Runtime**: Bun
- **Ports**: 3000 (primary), 3100 (colab)
