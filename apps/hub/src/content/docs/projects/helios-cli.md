## Overview

heliosCLI is the primary AI coding CLI for the Phenotype ecosystem. Built with a Rust core and TypeScript integrations, it provides unified access to Codex, Claude, and Gemini.

## Stack

- **Core**: Rust
- **Integrations**: TypeScript
- **Port**: 6000
