## Status

The `phenotype.us` site is currently offline. It was originally a Shopify-based storefront built approximately two years ago. That deployment has lapsed and the domain is pending redirection.

## Recovery Plan

The site will be rebuilt as a static Astro site hosted on Cloudflare Pages with a CNAME pointing `phenotype.us` to the Cloudflare Pages deployment.

### Phases

| Phase | Task | Status |
|-------|------|--------|
| 1 | Static Astro build with portfolio content | Planned |
| 2 | Deploy to Cloudflare Pages | Planned |
| 3 | Set CNAME from `phenotype.us` → Cloudflare Pages URL | Planned |
| 4 | Redirect `www.phenotype.us` | Planned |
