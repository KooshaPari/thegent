# 📊 TheGent Unified Agent Dashboard

## WP-17001: Next.js + Tailwind + Lucide

This is the unified control plane for TheGent.

### Key Features
- **Live Run Monitor**: Real-time visualization of agent runs and trace propagation.
- **Team Management**: Interface for multi-tenant team creation and RBAC assignment.
- **Governance Cockpit**: Overview of policy health, budget utilization, and drift detection.
- **Prompt Optimizer**: Integrated DSPy-inspired playground for prompt versioning.

### Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Components**: shadcn/ui
- **Icons**: Lucide React
- **State**: React Query + Zustand
