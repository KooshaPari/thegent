SOLUTION: PARETO FRONTIER ALGORITHM
================================================================================

DEFINITION:
  A model is "optimal" if NO other model is better on ALL metrics simultaneously.

DOMINANCE RULE:
  Model A dominates Model B if:
  - A.quality ≥ B.quality AND
  - A.speed ≥ B.speed AND
  - A.cost ≤ B.cost
  - (with at least one strict improvement)

ALGORITHM COMPLEXITY:
  Time: O(n²) where n = number of models
  For 11 models: ~121 comparisons, <1ms
  For 100 models: ~10K comparisons, <10ms
  Scalable: Can compute on every request

FRONTIER RESULT:

  2. MiniMax M2.5 ($0.79/M, 80.2% quality, very-fast) ← BEST VALUE
